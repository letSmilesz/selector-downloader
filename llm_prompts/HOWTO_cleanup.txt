КАК СОБРАТЬ ПРЕСЕТ ИЗ СЫРЫХ СЕЛЕКТОРОВ (для человека; в LLM не улетает)

ШАГ 0. Какие сниппеты брать и как урезать.
- Мелкие элементы (кнопки, label, select, спиннер): outerHTML целиком.
- Огромные контейнеры (лента ридера, оглавление): открывающий тег + первые 1-2
  дочерних блока + «…и ещё N таких же» + закрывающий тег. LLM не нужны повторы, нужен паттерн.
ВАЖНО: оставь в сниппете ОДИН блок комментария/попапа, если они есть в контейнере —
иначе LLM не увидит ловушку аватарок и image_selector будет ловить лица комментаторов.
- Копировать: F12 → Elements → ПКМ по узлу → Copy → Copy outerHTML.
- Вставлять в шаблон после селектора роли, с пробела или новой строки.

СЛОВАРЬ РОЛЕЙ (ЧТО КУДА КОПИРОВАТЬ):

[СТРАНИЦА ГЛАВЫ]
- content_container — Блок, содержащий ТОЛЬКО главу (картинки/текст). БЕЗ навигации,
  комментариев и рекламы. Примеры: div.text-content, #mangaBox.
- image_selector — <img> страниц манги или иллюстраций. Не должен ловить аватарки,
  иконки, рекламу, превью. Примеры: div[data-page] img, #mangaBox img.manga-img.
  Должен находить ВСЕ страницы (в консоли > 1). Не id одной картинки!
- text_selector — (Для ранобэ) Абзацы <p> с текстом строго внутри content_container.
- lazy_attr — (Если есть) Имя атрибута с реальной ссылкой (data-src), если в src
  заглушка. Иначе — пусто.
  Как проверить: откройте главу, ПКМ по картинке → Просмотреть код.
  Если в src полный путь (https://.../page_001.jpg) — оставьте пустым.
  Если в src мусор (data:image/..., 1x1.png), но есть другой атрибут с реальным
  путём — впишите его имя. Примеры: 'data-src', 'data-original', 'data-lazy-src'.
  Пишем только имя атрибута, без кавычек и без префикса.
  Отличие от image_selector: image_selector находит сами <img> элементы на странице,
  а lazy_attr говорит, из какого атрибута каждого <img> читать URL для скачивания.
- next_chapter_btn — Кнопка/ссылка «Следующая глава». Массив. Меняет URL главы
  (не страницы!). Может быть несколько (стрелки, кнопки) — указывай все.
  ВАЖНО: URL после клика должен вести на другую главу, а не ?page=2.
- prev_chapter_btn — Кнопка/ссылка «Предыдущая глава». Опционально.
- back_to_toc_btn — Ссылка возврата из ридера на страницу тайтла (к оглавлению).
- settings_button — Кнопка настроек ЧИТАЛКИ (шестерёнка). Должна открывать меню
  режимов, а не настройки сайта. Осторожно с дублями: шестерёнка часто лежит дважды —
  в скрытой справке (#helpHint) и в видимой плавающей панели (.floating-page-indicator).
  Copy selector бери из ВИДИМОЙ панели, иначе ensure_mode упрётся в display:none.
- web_mode_toggle / page_mode_toggle — (Внутри меню настроек) Тумблеры режимов
  «Лента» / «Постранично». В самом селекторе НЕ должно быть классов состояния
  (.active, .open, .selected), иначе скрипт не найдёт его в закрытом состоянии.
- page_select — Выпадающий список <select> СТРАНИЦ в футере (1, 2, 3...).
  Это именно <select>, а НЕ текстовый блок 'страница 5 из 20'.
  Нужен для определения общего числа страниц в главе через количество <option>.
  Пример: 'select.page-select', '.manga-pages select'.
- next_page_button — Кнопка «Следующая страница» (листает страницы внутри главы).
- loading_indicator — Спиннер/«Загрузка...», исчезающий после загрузки контента.

[СТРАНИЦА ТАЙТЛА (ОГЛАВЛЕНИЕ)]
- toc_link — Вкладка/кнопка «Главы», открывающая список.
- toc_container — Блок-обёртка, внутри которого лежат ссылки на главы.
- chapter_link — Сами ссылки <a> на главы. НЕ уникальный — матчит все ссылки глав.
  Примеры: a[href*='/read/'], a[href*='/vol']. Должен находить все главы в списке.
- hidden_chapters_btn — Кнопка разворота скрытых групп глав в оглавлении
  («Скрыто», «Показать ещё», «Показать с начала»).

[ОБЩЕЕ]
- dismiss_texts — ТЕКСТ на кнопках закрытия попапов («Принять», «×», «Закрыть»).
  НЕ селекторы! Для крестика без текста пиши «×».
  Может быть строкой (один текст) или массивом (несколько текстов).
  Пример: 'Да, мне есть 18' или ['Принять', 'Закрыть'].
- dismiss_selectors — CSS-селекторы ИКОНОЧНЫХ кнопок закрытия попапов
  (SVG-крестики, иконки без текста, где :has-text() не работает).
  Это не тексты кнопок, а именно селекторы элементов.
  Пример: 'button.modal-close-btn svg', 'a[aria-label="Close"]'.
  Массив строк. Отличается от dismiss_texts (там текст) и
  dismiss_remove_selectors (там контейнеры для скрытия целиком).
- dismiss_remove_selectors — CSS-селекторы контейнеров (реклама, оверлеи,
  информационные блоки), которые нужно скрыть целиком через display:none.
  Используется, когда у блока нет кнопки закрытия — скрипт прячет его сам.
  Как найти: откройте главу, найдите в DevTools рекламный оверлей или баннер,
  скопируйте его селектор. Каждая строка — один селектор.
  Пример: div[class^='csr-uniq'].
- navbar_hover_selector — (Опционально) CSS-селектор области, на которую нужно
  навести курсор, чтобы появились скрытые кнопки навигации. Нужен только если сайт
  прячет кнопки 'Следующая глава' / 'К оглавлению' в невидимую зону до hover-эффекта.
  В большинстве пресетов не требуется.
- banned_paths — Подстроки URL, запрещённые к скачиванию. Используется для защиты
  от заглушек, которые сайт отдаёт вместо реальных страниц.
  Как заполнить: откройте главу с заглушками, через DevTools посмотрите src одной
  из заглушек, сравните несколько src и найдите общую часть пути.
  Пример: src='/static/deleted1.png?t=111&u=0&h=XXX' — общая часть '/static/deleted',
  'deleted' или 'deleted1.png'. Любая из этих подстрок подойдёт.
  Каждая подстрока — с новой строки.
- meta_text_selector — Элемент с текстом «Том X Глава Y» на странице главы.
  Нужен для поиска глав без URL. Если чисел в тексте нет или оно одно — пиши «нет».
- meta_text_template — Точный шаблон текста meta_text_selector с плейсхолдерами
  {volume} и {number}. Пример: «Том {volume} Глава {number}», «{volume} - {number}».
  Может быть массивом шаблонов, если на сайте разные форматы для разных глав
  (обычные vs экстра/синглы). Пример: ["Том {volume} Глава {number}", "Сингл"].
- data_num_scale — Число (обычно 10, 100 или 1000). Применяется к атрибутам
  data-num / data-vol у элементов оглавления, когда сайт хранит номер главы
  масштабированным. Пример: data-num="12345", реальный номер главы = 123.45,
  значит scale=100 (12345 / 100 = 123.45).
  Если на сайте data-num = реальный номер главы — оставь пустым (null).
  Как проверить: в DevTools найди у ссылки главы атрибут data-num, сравни
  с номером, указанным в тексте ссылки. Если отличается в N раз — scale=N.
- chapter_name_selector — Элемент с названием главы (для имени файла). Опционально.
- marker_groups (rate_limit) — Группы маркеров для детекта баннера ошибки/лимита
  запросов (капча, бан по IP). Срабатывает, когда на странице совпали ≥2 разных групп
  одновременно И при этом нет полезного контента (картинок/текста).
  Логика: одиночный поп-ап — ещё не rate-limit; а вот сочетание
  'баннер + затемнение + отсутствие контента' — уже он.
  Формат: одна строка = одна группа, слова через запятую.
  Пример:
  лимит, превышен
  повторите, позже
  Если не уверены — оставьте пустым, детект будет только по отсутствию контента.
- volume_regex / chapter_num_regex — НЕ ЗАПОЛНЯЙ. LLM сама соберёт их из ссылок.

ШАГ 1. Заполни шаблон в конце llm_cleanup_prompt.md.
- Селектор: ПКМ по элементу → Copy → Copy selector.
- Несколько примеров одной роли — повтори строку роли.
- Роли нет — «нет».
- Для иконочных кнопок (шестерёнка, стрелки) копируй ВЕСЬ outerHTML кнопки/span
  вместе с иконкой-ребёнком: модель соберёт селектор через :has() или href.
  На порядок пунктов бокового меню не опирайся: он отличается между браузерами
  (расширения добавляют пункты) — nth-child там врёт.
- После вставки пресета проверь settings_button: клик должен открыть модалку
  с тумблерами режимов, а не настройки сайта и не путеводитель.
- Мета-элемент: селектор И видимый текст через «=»; если чисел в тексте нет или
  оно одно — пиши «нет».
- Проверь URL главы: если в нём нет номера главы — ищи data-num/data-vol в строках
  оглавления и ставь meta_text_selector на активную строку.
- ОГЛАВЛЕНИЕ: если список постраничный или начинается не с первой главы — найди
  кнопку «Показать с начала» и положи в hidden_chapters_btn.
- outerHTML крепи к роли с новой строки или через " | outerhtml: ", урежь до 1-2 детей.
- ⚠️ СКРЫТЫЕ И ВЫПАДАЮЩИЕ ЭЛЕМЕНТЫ: Тумблеры режимов (web/page), page_select,
  меню настроек и модалки часто рендерятся в DOM или получают нужные атрибуты
  ТОЛЬКО после клика. Открой меню/список вручную в браузере, чтобы элемент стал
  видимым, и только потом копируй селектор/outerHTML.
  ВАЖНО: В самом селекторе НЕ должно быть классов состояния (.active, .open,
  .selected), иначе скрипт не найдёт его в закрытом состоянии.
- href-ы глав: минимум один ДАЖЕ если глава одна и качаешь через «Глава по ссылке».

ШАГ 2. Скорми LLM: приложи заполненный файл в LLM/агенту (или вставь целиком в чат).
- Ответ = JSON пресета + блок «ПРОВЕРКА В КОНСОЛИ:».
- Ответ {"error": ...} — забыл заполнить шаблон; допиши и повтори.
- Есть блок «НУЖНО ДОПОЛНИТЕЛЬНО:» — приложи запрошенный HTML следующим сообщением
  (глава-web / глава-page / тайтл) и повтори: LLM дозаполнит роли вместо null.

ШАГ 3. Проверка в консоли (5 минут вместо часа отладки).
- Страница главы → F12 → Console → вставь группу «НА СТРАНИЦЕ ГЛАВЫ» → сверь числа.
- Страница тайтла → то же для группы «НА СТРАНИЦЕ ТАЙТЛА».
- Чтение результатов:
  length = 0                  → селектор мимо: правь в редакторе или повтори промпт;
  image_selector > ожидаемого → ловит аватарки/комменты: ограничь классом/атрибутом;
  image_selector = 1          → снова id одиночной картинки: нужен селектор через контейнер;
  tagName != 'IMG'            → попал в контейнер: добавь " img" или [data-page];
  match(...)?.[1] = undefined → регекс не захватывает номер, смотри href и группу 1.
  chapter_link крутится впустую / нашёл 0 глав → проверь, что это <a>:
  document.querySelectorAll('<селектор>:not([href])').length должно быть 0.
  Если >0 — снова контейнер: допиши " a" руками или требуй у LLM исправление.
- 📤 ЧТО СКИДЫВАТЬ LLM ДЛЯ ДОРАБОТКИ: Если консоль-блок показал ошибки,
  скидывай в чат ТОЛЬКО провалившиеся строки (где length не совпал с ожидаемым,
  вылез SyntaxError или null). Успешные проверки НЕ СКИДЫВАЙ.
  Исключение: если сломанный селектор логически связан с другим, скинь оба.
- ERR_BLOCKED_BY_CLIENT — твой адблок, игнорируй (в загрузчике адблока нет).

ШАГ 4. Сохрани JSON в presets/<имя_сайта>.json (без «copy» в имени).
- Открой «Пресеты» в загрузчике — пресет в списке, поля заполнены.

ШАГ 5. Тест-прогон: «Глава по ссылке» + одна глава; потом диапазон, если есть навигация.
- Красный статус «Не удалось извлечь номер главы» → шаг 3, регексы.
- Глава скачалась пустой / «не найдено URL изображений» → шаг 3, image_selector.
- Сайты с referer-защитой картинок (allhen-семейство): прямой заход на главу отдаёт
  заглушки (deleted1.png). Таким сайтам ставь старт с URL тайтла: движок кликнет главу
  в TOC и получит реальные картинки. «Глава по ссылке» / --single для них = битые
  картинки (referer-прогрев теряется). Обработка заглушек — через banned_paths.
- Если на сайте есть баннеры ошибок/лимитов — заполни marker_groups, чтобы движок
  мог их распознать и остановить скачивание с понятным сообщением.
