# Selector Downloader

Загрузчик манги и ранобэ: главы сохраняются архивами **CBZ** или папками с картинками,
ранобэ — в **EPUB** (текст + иллюстрации). Работает через настоящий браузер
Google Chrome (Playwright) с вашим постоянным профилем: куки, настройки сайта,
случайные задержки между главами (3–8 сек) — как при обычном чтении.

Вся сайто-специфика вынесена в JSON-пресеты (`presets/`) — движок не знает
о конкретных сайтах.

## Возможности

- Два интерфейса: GUI (Flet) и CLI.
- Манга: режимы чтения `web` (лента) и `page` (постраничный); ранобэ → EPUB.
- Диапазоны глав и томов, «N глав начиная с…», «глава по ссылке» (`--single`).
- Мягкий «Стоп» без потери уже скачанного.
- Прогресс по главам и страницам, уведомления «долгая загрузка», лог.
- Общий профиль браузера: один раз залогинился — куки работают для всех запусков.

Основная платформа — Windows.

## Требования

- Python 3.10+
- Пинированный Chrome for Testing (устанавливается одноразово через `scripts/setup_chrome.py`)
- Зависимости: `pip install playwright flet` (Flet 0.80+)

## Запуск

```
# Первичная настройка (одноразово)
python scripts/setup_chrome.py

# GUI (двойной клик на Windows)
run_gui.vbs   # тихий режим, без консольного окна
run_gui.bat   # консольный режим, видны ошибки

# GUI (вручную)
python frontend/main_window.py

# CLI
python main.py "<URL тайтла или главы>" --mode web
```

## Первый запуск

1. Нажмите **🔑 Залогиниться** — откроется браузер с общим профилем.
   Залогиньтесь на нужных сайтах, затем **⏹ Завершить логин**. Куки сохранятся.
2. Вставьте ссылку на тайтл (или главу), выберите режим, нажмите **Старт**.
3. Пресет подбирается автоматически по домену ссылки.

## Идеальный воркфлоу для нового сайта / своего пресета

1. Если пресет собран самостоятельно — сначала проверьте его работоспособность:
   скачайте одну главу в выбранном режиме.
2. Сделайте тестовые прогоны: пару глав в одном режиме, затем пару **других**
   глав в другом режиме. Именно других: браузер кэширует страницы, и повторный
   прогон тех же глав пройдёт мгновенно — результат будет непоказательным.
3. Выберите лучший режим. Один и тот же сайт может не работать в постраничном
   режиме, но отлично работать в веб — или медленно тянуть веб и летать в постраничном.
4. На скорость влияют VPN, состояние сети и сервер сайта. Сначала поэкспериментируйте
   с парой глав, потом запускайте весь диапазон.

## Как пользоваться GUI

- **Ссылка (URL)** — тайтл (оглавление) или конкретная глава.
- **Режим** — `web` / `page`. Для ранобэ игнорируется.
- **Главы: начальная/конечная** — пустая конечная = ровно одна глава; `-1` = «до конца».
- **Тома** — опционально.
- **Количество глав** — сколько скачать, начиная с начальной; перекрывает диапазон.
- **Глава по ссылке** — URL ведёт прямо на главу, поиск по оглавлению не нужен.
- **Папка вывода + «Создать подпапку»** — каждый запуск кладётся в `title1`, `title2`, …,
  чтобы разные тайтлы не перетирали друг друга.
- **Сохранить как CBZ** — выключить = главы папками с картинками.
- **Чистить темпы провальных глав** — выключите, чтобы оставить `.tmp`-папки для разбора.
- **Показать окно браузера** — оконный режим для диагностики.
- **Режим отладки** — подробный вывод, файловый лог и HTML-дампы.
- **Показать лог** — окно лога вместо таблицы результатов.

Задержки между главами фиксированные: 3–8 сек.

## Стоп

**Стоп** — мягкая остановка: флаг + сигнал процессу. Всё скачанное до стопа сохраняется:
манга пакуется в CBZ по мере скачивания каждой главы, ранобэ собирается в EPUB
из накопленного буфера. Текущая глава прерывается.

**Прервать сейчас** — осознанное убийство процесса: текущая глава и буфер ранобэ теряются.

Если процесс упал аварийно, следующий запуск может сообщить «Профиль занят» —
удалите файл `chrome_profile/.downloader.lock` вручную.

## Пресеты

Пресет — JSON-файл: селекторы сайта, регексы номеров глав/томов,
тексты попапов, маркеры баннеров лимита. Движок не знает о конкретных сайтах —
всё поведение приходит из пресета.

### Где брать готовые пресеты

Пресеты для поддерживаемых сайтов публикуются в Telegram-канале:
**https://t.me/manga_selector_downloader**

Скачайте нужные `.json`-файлы и положите в папку `presets/` рядом с `main.py`.
Пресет подбирается автоматически по домену ссылки; принудительный выбор —
кнопка **⚙ Пресеты** в GUI или `--preset <имя>` в CLI.

### Сборка своего пресета

1. Возьмите селекторы из DevTools сайта (см. `HOWTO_cleanup.txt`).
2. Скормите их LLM вместе с промптом `llm_prompts/full.md` → получите JSON +
   блок «ПРОВЕРКА В КОНСОЛИ».
3. Проверьте селекторы в консоли браузера (F12 → Console).
4. Сохраните JSON в `presets/<имя_сайта>.json` и откройте в редакторе GUI
   — проверьте поля.

**Лайфхак:** роль `hidden_chapters_btn` («разворот скрытых глав») можно использовать
хитрее. Если вместо кнопки «Показать скрытое» указать кнопку «Сортировка с первой» —
оглавление сразу откроется с первой страницы, и листать список не придётся.
Кнопка «Читать сначала» тоже подходит: скачивание в любом случае начнётся с первой главы.

## Ограничения

- Вкладки, открытые сайтом (реклама, глава в новой вкладке), закрываются:
  все поддерживаемые сейчас сайты навигируются в рамках одной вкладки.
- После аварийного завершения процесса lock-файл удаляется вручную (см. «Стоп»).

## Если что-то пошло не так

1. Включите **Режим отладки** и **Показать лог**, повторите запуск.
2. Включите **Показать окно браузера** — видно, на чём скрипт останавливается.
3. В корне проекта появятся `debug_*.html` — снимки страницы в момент сбоя.
4. Типичные симптомы:
   - «Не удалось извлечь номер главы» → регексы пресета;
   - глава скачалась пустой → `image_selector`;
   - заглушки вместо страниц → `banned_paths`; для сайтов с referer-защитой
     картинок запускайте с URL тайтла, а не «глава по ссылке».
     Некоторые сайты отдают 404 на прямой заход — загрузчик автоматически повторяет
     попытку через реферер-фолбэк (видно в debug-логе как `goto: статус 404...` + `_goto_cross_site...`).

## Advanced: что где лежит

| Путь | Назначение |
|---|---|
| `main.py` | CLI-точка входа |
| `frontend/main_window.py` | GUI (Flet) |
| `frontend/preset_window.py`, `frontend/config.py` | редактор пресетов, настройки GUI |
| `browser/driver.py` | запуск браузера: постоянный профиль, lock, антидетект |
| `browser/interceptor.py` | перехват картинок из кэша браузера + fetch-фолбэк |
| `engine/toc_walker.py` | оглавление: поиск нужной главы, клик по ссылке |
| `engine/reader.py` | скачивание главы (web / page / ранобэ), режимы, попапы |
| `engine/worker.py` | цикл глав по кнопке «дальше», флаг стопа |
| `core/` | лог + события, менеджер пресетов, имена файлов, задержки, дефолты |
| `output/archiver.py`, `output/epub.py` | сборка CBZ и EPUB |
| `scripts/gui_auth.py` | браузер логина |
| `scripts/setup_chrome.py` | устанавливает пинированный Chrome for Testing 152 |
| `scripts/pw_test.py` | режим разработчика: браузер под Playwright для отладки пресетов |
| `run_gui.bat` / `run_gui.vbs` | лаунчеры GUI для Windows (консольный / тихий) |
| `presets/*.json` | пресеты сайтов |
| `downloads/` | результат (по умолчанию) |
| `chrome_profile/` | постоянный профиль браузера. **Содержит ваши куки — не публикуйте.** |
| `.stop_download` | флаг-файл мягкой остановки |
| `debug_*.html` | дампы страниц (только режим отладки) |

## CLI

```
python main.py "<URL тайтла>" --mode web --count 3                 # 3 главы с начала
python main.py "<URL тайтла>" --mode web --chapters 5-10           # диапазон
python main.py "<URL тайтла>" --mode web --chapters 3--1           # с 3 до конца
python main.py "<URL главы>"  --mode web --single                  # ровно одна глава
python main.py --setup "<URL>"                                     # подготовка профиля вручную
```

Полезные флаги: `--headed` (окно браузера), `--debug`, `--no-cbz` (папки вместо CBZ),
`--volumes 1-3`, `--output <папка>`, `--preset <имя>`, `--keep-failed-temps`.
